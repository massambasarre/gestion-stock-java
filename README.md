# Gestion de stock Java

Gestion des produits, disponibilité des stocks, commandes et ventes.

## Technologies

Java, collections, sérialisation.

## Installation et utilisation

JDK requis. Les sources archivées nécessitent une remise en conformité avant compilation : plusieurs classes publiques figurent dans le même fichier. Ne pas considérer le projet comme prêt à exécuter.

## Contributions

Le rapport attribue à Khady Cisse et Massamba Sarre une contribution aux classes principales de gestion des produits, stocks et commandes.

## État et limites

Pas de build validé. Les objets sérialisés d’origine sont exclus ; ne jamais désérialiser des données non fiables.

Préparation du dépôt : nettoyage des fichiers générés et ajout de cette documentation. Aucun test fonctionnel de bout en bout n’a encore été effectué ; les commandes ci-dessus sont des indications dérivées des sources, pas une certification de fonctionnement.
